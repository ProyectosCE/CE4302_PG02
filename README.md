### Objetivo

Mediante el desarrollo de este proyecto, la persona estudiante aplicará conceptos de paralelismo a nivel de datos (Data-Level Parallelism) utilizando arquitecturas vectoriales, extensiones SIMD y procesamiento mediante GPU.

El objetivo principal consiste en diseñar e implementar un problema altamente paralelizable,
analizar su descomposición en operaciones vectoriales y evaluar su desempeño utilizando distintos modelos de paralelismo por datos disponibles en arquitecturas modernas.

La persona estudiante deberá comprender las diferencias entre paralelismo a nivel de instrucción, paralelismo a nivel de datos y paralelismo masivo en GPU, así como las implicaciones de estos modelos en el dise˜no de algoritmos de alto desempeño.
